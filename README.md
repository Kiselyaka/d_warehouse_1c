# Warehouse 1C

This repository is reserved for the Warehouse information system implemented on the 1C platform. It is intentionally not replaced with a Python service and does not participate in Docker Compose during Milestone 0.

## Structure

- `configuration/` — 1C configuration artifacts.
- `extensions/` — optional 1C extensions.
- `http-services/` — HTTP-service modules and related contracts when Warehouse integration begins.
- `docs/` — technical documentation for the 1C system.

No business flow, HTTP endpoint, event producer, or Integration Platform adapter is implemented in this milestone.
